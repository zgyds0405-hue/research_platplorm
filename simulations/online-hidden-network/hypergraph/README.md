# 局部树状超图上的节点上下线与渗流

## 底图和上下线机制

固定节点数 \(N\)、超边大小 \(h\) 和目标平均超度 \(z\)，从所有 \(h\) 元节点集合中均匀无放回抽取 \(\operatorname{round}(Nz/h)\) 条超边。节点超度指其所属的超边数。比较不同 \(h\) 时固定 \(z\) 和 \(N\)，因此预计超边总数随 \(1/h\) 变化。固定 \(h,z\) 令 \(N\) 增大时，稀疏随机超图的关联二部图局部趋向树状。例如 \(h=6,z=4\) 时，参与关联图四环的原节点比例从 \(N=2000\) 的 8.85% 降到 \(N=32000\) 的 0.61%。四环统计和实际平均剩余超度保存在 `topology.csv`。

所有节点以相同参数独立切换。隐藏等待时间的指数速率为 \(\lambda\)，在线等待时间的指数速率为 \(\mu\)。对每条超边 \(e\)，令 \(X_i(t)\) 为节点是否在线，超边状态为

\[
Y_e(t)=\prod_{i\in e}X_i(t).
\]

任一成员隐藏时，整条超边失效。所有成员重新在线才恢复原有超边上的连通性。有效超边的连通分量按原节点数计算，在线孤立节点各算一个大小为 1 的分量。\(L_1,L_2\) 分别是最大的两个分量，两个分量同样大时都计入，缺失的分量记 0。\(S=L_1/N\) 的分母为底图全部节点。

主实验取 \(h=2,3,4,6\)，\(z=2,4,8\)，\(N=2000,4000,8000,16000,32000\)。每个组合独立生成 10 张底图，静态和动态组逐张配对，共 600 张。横轴统一取 0.010 至 0.990 的千分位网格，并补齐理论阈值，共 988 个概率值。静态组按 \(p\) 独立保留节点，每图取 8 次。动态组从全在线出发，固定 \(\mu=0.01\)，取 \(\lambda=\mu p/(1-p)\) 使 \(p_*=p\)。以 \(\tau=1/(\lambda+\mu)\) 为单位，在 \(10\tau\) 首次采样，此后每 \(3\tau\) 一次，共 8 次。精确的两态转移等价于以概率 \(e^{-\Delta t/\tau}\) 保留原状态，其余情况按 \(p_*\) 重新抽取。各概率点共享均匀随机数以加速扫描，每个概率点的边际及动态快照间的条件分布满足模型。统计上先平均同一张图的快照，再在 10 张独立图上平均。

## 理论核对

从一个在线节点沿一条超边向外探索，该超边其余 \(h-1\) 名成员都在线的概率为 \(p^{h-1}\)。泊松极限下，沿关联关系进入新节点后，其平均剩余超度为 \(z\)。平均分支数为 \(z(h-1)p^{h-1}\)，所以

\[
p_c=[z(h-1)]^{-1/(h-1)}.
\]

记 \(a\) 为给定节点在线时连接到巨分量的概率。局部树状极限下，一条关联超边能通往巨分量的概率为 \(p^{h-1}[1-(1-a)^{h-1}]\)。泊松超度给出

\[
a=1-\exp\{-zp^{h-1}[1-(1-a)^{h-1}]\},\qquad S_\infty=pa.
\]

使用非负最大解。\(h=2\) 恢复稀疏普通随机图的点渗流方程。\(z=2\) 时 \(h=2\) 和 \(h=3\) 的阈值都为 0.5。动态稳态的节点状态为独立伯努利变量。设 \(p=p_*\) 时，在同一张底图上两组快照具有相同分布。超边稳态有效率为 \(p_*^h\)，共享成员的超边状态一般相互依赖。模型参照 [Bianconi & Dorogovtsev，Theory of percolation on hypergraphs](https://doi.org/10.1103/PhysRevE.109.014306)。

五组图均有矢量 PDF、SVG 与 600 dpi PNG。主图每组显示 25 个仿真点。全部扫描值可在 Excel 或压缩 CSV 中查阅。稳态相图描绘有限规模观测，超临界巨分量方程用于理论对照。有限尺度外推使用五个规模的平均 L₂ 峰值，自由拟合截距，并附去掉 N=2000 的重拟合。阈值和配对差的 95% 区间来自 2,500 次按整张底图配对重抽的百分位估计。稳态纵坐标、上线事件和时间相关的区间按底图间方差估计。表列相对误差先求两组跨图均值，再将均值差取绝对值、除以传统组均值。

时序实验中，初始全在线，节点在线概率 \(p(t)=p_*+(1-p_*)e^{-t/\tau}\)，有效超边期望比例为 \(p(t)^h\)。稳态时，超边自相关函数为 \([p(t)^h-p_*^h]/[1-p_*^h]\)，此处 \(t\) 是时间滞后。另由指数等待时间可得，一条有效超边的平均连续在线时长为 \(1/(h\mu)\)。

事件实验从稳态上线事件的条件分布直接取样。每次从所有节点编号中均匀指定一个触发节点，将该节点设为隐藏，其余节点独立按 \(p_*\) 在线。每张底图每个概率抽取 200 次，共 32,000 个事件样本。定义 \(r\) 为恢复的超边所接入的原连通分量个数，重复接入同一分量只计一次。若恢复 \(b\) 条超边，其理论平均值为 \(zp_*^{h-1}\)，对有限底图可用实际平均超度替换 \(z\)。代码核验新分量节点数为 \(1+\sum_{j=1}^{r}s_j\)，最大分量的增量为它超过旧最大分量的正部分。

## 复现与明细

使用 Linux、g++ 和 Python 3.12。运行依赖为 NumPy、SciPy、Matplotlib、XlsxWriter，核验脚本还用到 OpenPyXL 和 Pillow。

```sh
python simulate.py
python events.py
python topology.py
OPENBLAS_NUM_THREADS=1 python evaluate.py
python figures.py
python workbook.py
python verify.py
```

已有 `observations.npz` 与 `event_samples.csv` 时，可以直接从评估步骤重建汇总和图片。`observations.npz` 的 `sums` 维度依次为超边大小、平均超度、规模、配对图、机制、概率、统计量。机制顺序为传统、动态，统计量顺序为 L₁、L₂、有效超边数、在线节点数、连通分量数。数值为 8 个快照的和。随机种子和轴坐标随数据保存。独立参考实现用完整有效超边的关联图做 BFS，核验连通分量，并验证 60 组峰位、12 组外推和 59,280 项稳态误差。

本实验固定均匀超边大小，并比较固定平均超度的随机超图。有限规模峰位会漂移。重抽样区间描述抽样不确定性，有限尺寸拟合的系统误差通过删去最小规模的敏感性结果单独呈现。
