# ER 网络的传统点渗流与动态激活对照

两组在相同的占据概率取值上比较最大连通分量占总节点数的比例。每个 k 从 157 个实测概率中选取相同的 25 个横坐标，以空心正方形显示，包含两端点和三个理论阈值。完整数据保存在 summary.csv 中。图中颜色区分底图期望平均度 k。同色竖虚线标注大规模 ER 网络的理论阈值 p_c = 1/k，k 为 2、4、8 时分别为 0.500、0.250、0.125。矢量文件位于 figures/，其中 static 和 dynamic 为独立图，comparison 为左右排列的对照图。PNG 为 600 dpi。

## 实验参数

- 节点总数 M = 4,000，底图期望平均度 k = 2、4、8，ER 连边概率为 k/(M−1)。每个 k 生成 24 张独立底图。同一底图用于两个机制及所有横坐标点。
- 横坐标从 0.01 至 0.99，保留原有 71 个点，在全区间补充间隔 0.01 的网格，并在每个理论阈值左右 0.01 的窗口补充间隔 0.002 的网格。每个 k 在每组各有 157 个概率点，所有散点均由仿真计算。传统组每次独立地以概率 x 保留各节点。
- 动态组固定下线率 μ = 0.01，每个 x 取上线率 λ = μx/(1−x)，使稳态在线概率等于 x。每个参数组合从全在线启动。以 τ = 1/(λ+μ) 为时间单位，第一次在 10τ 观测，此后每隔 3τ 观测一次，合计 8 次。同一条轨迹中各次观测使用两状态连续时间马尔可夫链的精确转移概率进行采样。
- 每次只在保留或在线节点的底图诱导子图中计算 L₁，孤立的在线节点计入。分母始终为 M。传统组每张底图也取 8 个样本。
- 每个方块显示 24 张底图均值的平均值。summary.csv 保存以底图为独立单位计算的逐点 95% t 置信区间，以及配对差（动态减传统）的逐点区间。

## 复现

使用上级目录的 requirements.txt 安装依赖后，在本目录执行：

```sh
python percolation.py
```

replicates.csv 保存每张底图、每个概率点的平均 L₁/M 和实际在线比例。summary.csv 保存总体均值和区间。固定随机种子为 20261124。

## 稳态最大连通分量对比表

安装 XlsxWriter 后执行 `python steady_table.py`，使用种子 813402，每个参数组合进行 10 次独立底图配对仿真，每次取 8 个快照的均值。tables/ 中的 Excel 与 CSV 含 471 行配对结果（每个 k 有 157 个概率），提供平均最大连通分量的节点数、占比和相对误差。先分别对 10 次结果取均值，再对两组均值的差取绝对值，除以传统组均值得到相对误差。Excel 含 4,710 条配对明细。CSV 的误差列以百分数记录。
