# ER 网络的传统点渗流与动态激活对照

两组在相同的占据概率取值上比较最大连通分量占总节点数的比例。图中每条曲线对应一种底图期望平均度。矢量文件位于 figures/，其中 static 和 dynamic 为独立图，comparison 为左右排列的对照图。PNG 为 600 dpi。

## 实验参数

- 节点总数 M = 4,000，底图期望平均度 k = 2、4、8，ER 连边概率为 k/(M−1)。每个 k 生成 24 张独立底图。同一底图用于两个机制及所有横坐标点。
- 横坐标从 0.01 至 0.99，包含间隔 0.025 的主网格，并在 1/k 附近加密。传统组每次独立地以概率 x 保留各节点。
- 动态组固定下线率 μ = 0.01，每个 x 取上线率 λ = μx/(1−x)，使稳态在线概率等于 x。每个参数组合从全在线启动。以 τ = 1/(λ+μ) 为时间单位，第一次在 10τ 观测，此后每隔 3τ 观测一次，合计 8 次。同一条轨迹中各次观测使用两状态连续时间马尔可夫链的精确转移概率进行采样。
- 每次只在保留或在线节点的底图诱导子图中计算 L₁，孤立的在线节点计入。分母始终为 M。传统组每张底图也取 8 个样本。
- 各曲线显示 24 张底图均值的平均值。阴影为以底图为独立单位计算的逐点 95% t 置信区间。summary.csv 中另有配对差（动态减传统）的逐点区间。

## 复现

使用上级目录的 requirements.txt 安装依赖后，在本目录执行：

```sh
python percolation.py
```

replicates.csv 保存每张底图、每个概率点的平均 L₁/M 和实际在线比例。summary.csv 保存总体均值和区间。固定随机种子为 20261124。
