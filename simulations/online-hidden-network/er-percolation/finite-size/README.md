# ER 网络的有限尺寸标度实验

finite_size.xlsx 提供有限规模峰位、临界点外推、理论阈值处的最大分量三张数据表及统计说明。peaks.csv、extrapolation.csv、critical_l1.csv 分别对应三张表。mean_scan.csv 给出 15 种规模与平均度组合的全部平均扫描结果。

## 实验

每个平均度 k（2、4、8）和节点数 M（2000、4000、8000、16000、32000）使用 10 张独立 G(M,k/(M−1)) 底图，传统与动态组逐张配对。每张底图每组采样 8 次，孤立在线节点也计入分量。若没有第二个分量，L₂ 记为 0。L₁ 与 L₂ 可以相等。每次归一化均除以底图节点总数 M。

动态组从全在线开始，μ=0.01，λ=μx/(1−x)，τ=1/(λ+μ)。第一次观测为 10τ，后续间隔为 3τ。在长度为 dτ 的间隔上，每个节点以 exp(−d) 的概率保留旧状态，其余节点以概率 x 重新抽取在线状态。这给出指数上下线过程的精确观测时刻转移概率。

不同横坐标共用随机数。静态组每个快照对每个节点抽 U，给定 x 时取 U<x 的节点；动态组对每个节点按上述转移保留旧 U 或重新抽 U，初始 U=0。对同一快照按 U 排序、递增占据节点，用并查集和分量大小的有序多重集合记录 L₁、L₂。静态与动态组各有独立的节点随机数。逐概率点的边际采样遵循指定的模型，横坐标之间的相关性在配对整条曲线的重抽样中保留。

## 找峰与外推

以 0.01–0.99、步长 0.01 粗扫。取两组粗峰两侧各至少 0.030 的公共窗口，步长 0.001 找峰。排序扫描可同时给出全区间 981 个细网格点，用于复核全局最大值；若峰在窗口边界或窗口遗漏更高的峰，则扩展窗口。先对 8 个快照取均值，再对 10 张底图取均值，取平均 L₂ 的峰位。并列时依概率从小到大选取首个最大值。

外推采用五个规模的无权最小二乘，用 p_peak=b+aM^(−1/3) 的截距估计热力学极限。另给出去掉 M=2000 后的截距。L₁ 临界指数由理论阈值处的五个平均节点数作对数回归得到。对 10 张底图按配对整条曲线进行 5000 次 bootstrap，各规模独立重抽；每次重新找峰、计算截距和指数。报告逐项 95% 百分位区间。只有 10 张底图，区间精度有限，且不含网格离散化和外推模型误差。

## 数据与复现

paired_runs.npz 保存 10 次配对明细。component_sums 维度为 [k, M, 配对底图, 概率, 统计量]，统计量依次为传统 L₁、传统 L₂、动态 L₁、动态 L₂。存储值为 8 个快照的节点数之和，除以 snapshots 得到每张底图的均值。其他数组给出对应坐标、种子和 μ。

在含 g++ 的 Linux 环境中使用 Python 3.12、NumPy、NetworkX、SciPy、XlsxWriter。在本目录运行：

```sh
python simulate.py
OPENBLAS_NUM_THREADS=1 python analyze.py
```

已有 paired_runs.npz 时，只需第二条命令即可重建表格。底图和节点随机种子为 487219，bootstrap 种子为 590273。
