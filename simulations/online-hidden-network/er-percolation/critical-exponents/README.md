# 普通 ER 网络的临界序参量

原先两幅全区间图保留在主图上排，左列为传统随机点渗流，右列为马尔科夫节点上下线。主图下三排分别显示临界放大、超临界双对数关系、理论阈值处的规模依赖。配套图 er_scaling_collapse 按 k 分面比较六个规模的有限尺寸塌缩。两套图均以矢量 PDF、可编辑 SVG 和 600 dpi PNG 提供。

## 实验数据

- ER 底图 \(G(M,k/(M-1))\)，\(k=2,4,8\)，\(M=1000,4000,16000,64000,256000,1024000\)。
- 每个 \((k,M)\) 独立生成 40 张底图。每张供两机制配对使用，每个概率每组取 8 个快照。先取每张图的快照均值，再对 40 张底图平均。主图上排读原对照数据，其余均为本轮仿真。
- 传统组以概率 \(p\) 独立保留节点。动态组从全在线开始，\(\mu=0.01\)，\(\lambda=\mu p/(1-p)\) 令稳态 \(p_*=p\)。在 15 个弛豫时间后首次观测，之后每隔 3 个弛豫时间观测一次。采用连续时间两态链的精确转移核。边在两个端点在线时有效。
- \(S=\mathbb E[L_1]/M\)，分母为全部节点。缩放窗口在 \(x\in[-4,4]\) 上均匀布 33 点，\(x=(kp-1)(M/k)^{1/3}\)。另在 \(\epsilon=kp-1\in[0.012,0.30]\) 用 41 个对数等距的正值补充超临界拟合区。相同底图的一条扫描曲线共享随机数，各概率点的边际分布由对应占据率确定。
- `paired_runs.npz` 的 `k4_n64000` 等数组按底图、概率、统计量排列，末维顺序为传统 \(L_1,L_2\) 和动态 \(L_1,L_2\)。除以 snapshots 得图内均值。概率轴由各规模的 x 网格和正侧补充网格的并集生成。

## 两个指数

稀疏 ER 网络的理论临界值为 \(p_c=1/k\)。热力学极限的序参量满足 \(S_\infty=p(1-e^{-kS_\infty})\)。记 \(u=kS_\infty\)，展开 \(u=(1+\epsilon)(1-e^{-u})\) 的正解可得 \(u=2\epsilon-2\epsilon^2/3+O(\epsilon^3)\)，因此超临界序参量指数 \(\beta=1\)。临界点最大分量的节点数随 \(M^{2/3}\) 标度，临界占比则随 \(M^{-1/3}\) 标度。有限尺寸塌缩使用横坐标 \(x\)，及纵坐标 \(kS(M/k)^{1/3}\)。横轴中的 \(M/k\) 是在 \(p_c\) 附近的在线节点规模。

在两个最大规模上，用 \(0.08\le\epsilon\le0.20\) 为主窗口。浅蓝背景表示这个窗口。对组均值分别做简单的对数直线拟合和带一阶曲率项的拟合 \(\log(kS)=A+\beta\log\epsilon+C\epsilon\)。主图标注带曲率项的 \(\beta\)。另报告两个替代窗口 \([0.06,0.16]\) 和 \([0.10,0.24]\)。表格最后一列把相同拟合应用于精确 ER 极限曲线，用以量化有限拟合窗对斜率的影响。

临界占比指数用六个规模上 \(\log S(p_c)\) 对 \(\log M\) 的斜率估计。另给出去掉 \(M=1000\) 的拟合。区间为 3000 次以独立底图为单位的配对 bootstrap 百分位区间。两个机制的配对底图在同一重抽样中使用同一编号，各规模独立抽样。区间反映底图和快照的抽样误差。对拟合窗、网络规模的敏感性另列于表中。所有拟合以理论阈值为基准，检验的是阈值附近的标度指数。

## 数值结果

最大规模 \(M=1{,}024{,}000\) 在主窗口上的估计如下，区间为逐项 95% 配对底图重抽样区间。

| k | 传统 β | 马尔科夫 β | 两组 β 之差（马尔科夫减传统） |
|---:|---:|---:|---:|
| 2 | 0.992 [0.972, 1.011] | 1.005 [0.987, 1.023] | 0.013 [−0.013, 0.041] |
| 4 | 0.995 [0.967, 1.024] | 1.010 [0.983, 1.039] | 0.015 [−0.021, 0.049] |
| 8 | 1.013 [0.964, 1.062] | 1.040 [0.997, 1.085] | 0.027 [−0.043, 0.100] |

精确 ER 极限曲线在该窗口上的直接双对数拟合斜率为 0.963，带曲率项时为 0.996。仿真的直接拟合斜率为 0.962–0.976。更近的窗口 [0.06,0.16] 对有限尺寸更敏感，最大规模的 k=8 动态组给出 1.105 [1.059,1.153]。在临界点处，六个规模得到的占比斜率介于 −0.347 和 −0.332。k=2 传统组的六规模区间略偏离 −1/3，去掉最小规模后的区间覆盖 −1/3。

## 复现

使用 Python、NumPy、SciPy、NetworkX、Matplotlib、XlsxWriter 和可编译 C++17 的 g++。在本目录运行：

```sh
python run_critical.py
OPENBLAS_NUM_THREADS=1 python analyze.py
python plot.py
```

run_critical.py 复用上一级 finite-size 目录的并查集代码和检查。绘图读取上一级原始扫描 summary.csv。完整压缩包保留这些相对路径。已有 `paired_runs.npz` 时，直接从分析步骤重建表格和图片。
